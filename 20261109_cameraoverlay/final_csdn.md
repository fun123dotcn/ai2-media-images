# 拍出和上次一模一样的照片：App Inventor 新拓展「层叠相机」

摘要：装修进度、绿植生长、健身姿势、临摹对比……这些记录都要求「同一个角度拍两次」，可手持拍摄最难的就是角度对齐。新拓展「层叠相机」在相机实时取景上叠一张半透明的上次照片：挪动手机让两层画面重合，按快门就是一张角度对齐的对比照，拍出的照片还自带半透明参考层。一个属性、两个方法就能用。

## 同一个角度拍两次，为什么这么难

用手机拍「前后对比」照的人都有体会：第一张随手一拍挺满意，过些天拍第二张，怎么站都对不回原来的角度——盆栽显得大了、门框歪了、姿势对不上。肉眼估角度，十次有八次偏。

这类场景其实很常见：

- 装修进度每周一拍，最后拼成成长册；
- 绿植一天一张，记录长叶开花；
- 健身自拍对比，看动作有没有变形；
- 临摹字帖、画画，想知道这次比上次像了多少。

画家临摹有个老办法：把原稿垫在纸底下，照着描。层叠相机把这个办法搬进了手机——在相机的实时画面上，叠一张上次拍的照片，而且只叠一半透明度。你一边看实景，一边看半透明的「标准答案」，挪手机、进退几步，直到两层画面重合，这一刻按快门，两张照片的角度就严格一致了。

## 快速上手：三步拍出第一张对比照

设计器里拖一个垂直布局当取景框（高度 300 像素左右），导入拓展后把层叠相机的 PreviewHost（预览宿主）属性指向它，再放一个拍照按钮：

![开相机、拍照、把照片接力成参考底图](https://i-blog.csdnimg.cn/direct/c695e4dfdd8747fc885b820c413213bb.png)

打开应用自动开相机（相机权限会自动申请）。第一张是普通照片；从第二张起，取景框里就浮着上一张的半透明影子，对齐它，再按快门。拍完的照片在 GotPicture 事件里交给你，示例把它设回 ReferenceImage——下一张的参考层就这么自动接力下去。

![左：第一张普通照片；右：第二张取景上浮着半透明的上一张，挪动手机对齐（示意图）](https://i-blog.csdnimg.cn/direct/e8c743be14744b5f88a039bf5c614703.png)

## 参考层多透明，你说了算

默认透明度 50：屏幕上一半实景、一半参考图。接个滑动条实时调，想看清实景就调低，想紧盯参考就调高：

![参考层透明度 20 / 50 / 80：越低实景越清楚（示意图）](https://i-blog.csdnimg.cn/direct/1198402bccb24ef9812157f99ce456f9.png)

![滑动条实时调参考层透明度](https://i-blog.csdnimg.cn/direct/17af74a1239840e8a88039383880ee5b.png)

参考图怎么铺满取景框，由 FitMode 属性决定，三档：stretch 拉伸铺满（可能变形）、fit 完整显示（可能留边）、crop 裁切铺满（默认，不变形）。拍对比照用默认的 crop 就行；参考图和取景框比例差得多时，换 fit 看全图再对齐。

另外两个小开关也常用：CameraFront 用前置摄像头（自拍对比动作）；TorchEnabled 拍摄时开手电筒补光。

## 原理：两层画面，一个透明度

拓展的原理一句话能说清：取景框里其实叠着两层。下层是相机的实时画面，从不动它；上层是一张 ImageView 显示的参考照片，透明度只作用在这一层。屏幕上每个点，都是参考图和实景按透明度混出来的——透明度 50，就是一半一半。所以看着是「照片半透明、相机画面实」，其实是「实的不透明在下、半透明的浮在上」。

![原理：下层相机实景 + 上层半透明参考图，混合成屏幕所见（示意图）](https://i-blog.csdnimg.cn/direct/5ba24aab04a94f70b8a7d27a3e082008.png)

拍照那一刻，相机交出的本来是干净的原始照片，参考层只是屏幕上的显示。拓展在保存前把参考层按同样的透明度「烘」进照片——SaveWithOverlay 属性默认开启，拍出来的照片，和你按快门那刻屏幕上看到的一模一样；想要不带参考层的干净原片，把它关掉即可。

## 属性、方法和事件，两张表看全

| 属性 | 默认 | 作用 |
|------|------|------|
| PreviewHost | 空 | 取景画面显示在哪个布局（垂直/水平布局） |
| Opacity | 50 | 参考层透明度 0～100，0 全透、100 不透明 |
| ReferenceImage | 空 | 参考底图：素材名或照片路径，GotPicture 的路径直接能用 |
| FitMode | crop | 参考层铺法：stretch 拉伸 / fit 完整 / crop 裁切 |
| CameraFront | 假 | 用前置摄像头 |
| TorchEnabled | 假 | 拍摄时开手电筒 |
| SaveWithOverlay | 真 | 拍出的照片是否带半透明参考层 |

方法和事件如下，出错的提示全部是中文，照着改就行。

| 成员 | 类型 | 作用 |
|------|------|------|
| StartPreview | 方法 | 开相机、开始预览（自动申请相机权限） |
| TakePicture | 方法 | 拍照，完成后触发 GotPicture |
| StopPreview | 方法 | 停预览并释放相机，别的应用才能用相机 |
| ClearReference | 方法 | 临时清掉参考层（ReferenceImage 属性不变） |
| CameraReady | 事件 | 相机就绪，可以调透明度、拍照 |
| GotPicture | 事件 | 拍照完成，参数是照片的保存路径 |
| CameraError | 事件 | 出错提示，如相机被其它应用占用 |

## 三个注意事项

| 事项 | 说明 |
|------|------|
| 先 StartPreview 再拍照 | 相机没启动就拍照，提示「相机未启动」不会崩溃 |
| 宿主必须是布局 | PreviewHost 指到图像、标签这类普通组件会提示错误，用垂直/水平布局 |
| 参考层不会自动更新 | GotPicture 里要自己把路径设回 ReferenceImage，下一张才有参考（本文示例已带） |
